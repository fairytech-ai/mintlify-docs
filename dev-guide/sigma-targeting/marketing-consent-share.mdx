Sigma 모수 타겟팅은 마케팅 수신동의를 받은 사용자를 대상으로 이루어집니다. 고객사가 보유한 사용자 수신동의 정보를 페어리로 안전하게 전달해 주셔야 합니다.

## 공유 방법

- **서버 간 API**: 고객사 서버에서 페어리 서버로 수신동의 정보를 보내는 방식
- **사용자 단위 동의**: 하나의 userId 기준으로 수신동의 / 메시지 채널(SMS, 이메일, 푸시 등) 정보 관리

## 전달 항목

| 필드 | 설명 |
| --- | --- |
| `userId` | 고객사 서비스의 유저 식별자 |
| `consentStatus` | 수신동의 여부 (true/false) |
| `channels` | 동의한 메시지 채널 목록 |
| `consentTimestamp` | 동의 시점 |

<Note>
  세부 API spec과 인증 방식은 사전에 공유되는 API 문서를 참고해 주세요.
</Note>
