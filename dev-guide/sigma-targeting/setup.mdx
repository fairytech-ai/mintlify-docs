## 사전 준비

Sigma 모수 타겟팅을 이용하기 위해 페어리와 사전 계약이 필요합니다. 담당자(`eng@fairytech.ai`)에게 연락 후 프로젝트용 API Key를 전달받아 주세요.

## 연동 단계

1. 명확한 타겟 조건을 정의합니다.
2. 마케팅 수신동의 정보를 페어리로 공유합니다.
3. 페어리 콘솔에서 캐페인을 설정합니다.
4. 실행 결과를 리포팅합니다.

<Note>
  마케팅 수신동의 공유 방법은 [마케팅 수신동의 공유](/dev-guide/sigma-targeting/marketing-consent-share) 문서를 참고하세요.
</Note>
