캐시백 실적 생성 알림 등 페어리 서버에서 발송하는 푸시 알림을 수신하려면 Firebase Cloud Messaging(FCM) 설정이 필요합니다. 사용 중인 제품과 관계없이 서버 발송 알림을 이용하는 경우 공통으로 적용됩니다.

## Setup

### 1단계: 프로젝트에 Firebase 추가하기

Google 공식 가이드를 따라 Android 프로젝트에 Firebase를 추가합니다.

- 참고: _Firebase Android 설정 가이드_ ([https://firebase.google.com/docs/android/setup](https://firebase.google.com/docs/android/setup))

### 2단계: Firebase Cloud Messaging API 활성화

Google Cloud 콘솔에서 **앱과 연결된 프로젝트**를 선택한 뒤, [**Firebase Cloud Messaging API**](https://console.cloud.google.com/apis/library/fcm.googleapis.com) 를 활성화합니다

<Frame>
  ![Image](/images/image.png)
</Frame>

### 3단계: 서비스 계정 만들기

다음으로 Fairy가 FCM 토큰 등록 시 인증된 API 호출을 할 수 있도록 새 서비스 계정을 생성합니다.

**Google Cloud** \> **Service Accounts** 으로 이동하여 프로젝트를 선택한 뒤, **CREATE SERVICE ACCOUNT**를 클릭합니다.

<Frame>
  ![Image](/images/image-1.png)
</Frame>

서비스 계정 이름, ID, 설명을 입력하고 **CREATE AND CONTINUE** 선택하세요.

역할(Role) 필드에서 **Firebase Cloud Messaging API Admin**을 선택하세요.

(더 제한적인 접근 권한이 필요하다면 `cloudmessaging.messages.create` 권한이 있는 [custom role](https://cloud.google.com/iam/docs/creating-custom-roles)을 생성해 선택하세요.)

⚠️주의사항: **Firebase Cloud Messaging Admin**이 아니라 반드시 **Firebase Cloud Messaging API Admin**을 선택해야 합니다.

<Frame>
  ![Image](/images/image-2.png)
</Frame>

### 4단계: JSON 자격 증명 생성

FCM 서비스 계정을 위한 JSON Credentials를 만듭니다.

Google Cloud IAM & Admin에서 Service Accounts 을 선택한 뒤, 위에 만든 FCM service account를 찾고, **Actions** \> **Manage Keys**로 이동하세요.

<Frame>
  ![Image](/images/image-3.png)
</Frame>

Add Key \> Create new key를 선택합니다.

<Frame>

**JSON**을 선택한 뒤 **CREATE**를 클릭합니다.

## 알림 표시하기

### 1. 종속성에 Cloud Messaging 추가하기

build.gradle 에 **Firebase Messaging** 과 **Moment SDK(push 확장)** 를 추가합니다.

<Note>
  `{SDK_ARTIFACT_ID}`와 `{SDK_VERSION}`에는 Fairy에서 전달한 고객사별 SDK artifact ID와 버전을 입력합니다.
</Note>

```text
plugins {
	id("com.google.gms.google-services")
}

dependencies {
	implementation("com.google.firebase:firebase-messaging:+")
	implementation "ai.fairytech:{SDK_ARTIFACT_ID}:{SDK_VERSION}"
}
```

AndroidManifest.xml 에 알림 권한을 추가합니다.

```bash
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
```

### 2. FirebaseMessagingService 생성/등록

- FirebaseMessagingService 를 상속받아 **토큰 수신** 및 **메시지 수신**을 처리합니다.
- AndroidManifest.xml 에 해당 서비스를 등록합니다.

```kotlin
class CustomFcmService : FirebaseMessagingService() {
    override fun onNewToken(token: String) {
    }

    override fun onMessageReceived(remoteMessage: RemoteMessage) {
    }
}
```

```xml
<service
    android:name=".CustomFcmService"
    android:exported="false">
    <intent-filter>
        <action android:name="com.google.firebase.MESSAGING_EVENT" />
    </intent-filter>
</service>
```

### 3. MomentSDK 를 FirebaseMessagingService 와 연동하기

```kotlin
import ai.fairytech.moment.MomentSDK
import ai.fairytech.moment.exception.MomentException
import ai.fairytech.moment.MomentPush

class CustomFcmService : FirebaseMessagingService() {

    override fun onNewToken(token: String) {	
				// token 등록
				MomentPush.addDeviceToken(token, object: MomentSDK.ResultCallback {
					override fun onSuccess() {
					}
					
					override fun onFailure() {
						Log.w("CustomFcmService", "Failed to set token to moment")
					}
				})
    }

    override fun onMessageReceived(remoteMessage: RemoteMessage) {
        if (MomentPush.isFairyMessage(message)) {
	        MomentPush.handleMessage(message)
        }
    }
}
```
