# 연동하기

> Sigma 연동, user attribute 등록 및 마케팅 푸시 수신 설정

<Tip>
  Sigma는 `userId` 없이 사용할 수 있습니다. 타겟팅에 사용할 user attribute와 마케팅 푸시 수신 가능 여부를 SDK로 전달합니다.
</Tip>

## 사전 준비

<Warning>
  다음 설정을 먼저 완료하세요.

  - [시작하기 > Android Setup](/ko/dev-guide/getting-started/setup)
  - [공통 기능 > FCM 설정하기](/ko/dev-guide/common/fcm)
</Warning>

## STEP 1) 앱 시작 시점에 init 호출하기

`Application#onCreate`에서 `init`을 호출합니다. Sigma 관련 데이터 초기화가 함께 수행됩니다.

다음은 설정 예시입니다.

```kotlin
class MyApplication : Application() {
    override fun onCreate() {
        super.onCreate()

        val moment = MomentSDK.getInstance(this)
        moment.init(
            config,
            object : MomentSDK.RestartResultCallback {
                override fun onSuccess(resultCode: MomentSDK.RestartResultCode) {}

                override fun onFailure(exception: MomentException) {}
            },
        )
    }
}
```

## STEP 2) 마케팅 푸시 수신 가능 여부 전달하기

마케팅 푸시 수신 가능 여부가 최신으로 유지될 수 있도록 로그인 시점과 메인 화면 진입 시점에 `setMarketingPushEnabled`와 `setNightMarketingPushEnabled`를 호출합니다.

다음은 설정 예시입니다.

```kotlin
MomentSDK.getInstance(context).setMarketingPushEnabled(true)
MomentSDK.getInstance(context).setNightMarketingPushEnabled(true)
```

<Tip>
  마케팅 알림을 발송하려면 `setMarketingPushEnabled(true)`를 최소 한 번 호출해야 합니다. 21:00부터 08:00까지 마케팅 알림을 발송하려면 `setNightMarketingPushEnabled(true)`도 호출해야 합니다.
</Tip>

<Note>
  값이 변경된 경우에만 서버에 업로드되므로 같은 값으로 반복 호출해도 서버 요청은 생략됩니다.
</Note>

## (OPTIONAL) user attribute 전달하기

Sigma 타겟팅에 사용할 user attribute를 `setUserAttributes`로 전달합니다. 해당 Attribute로 유저를 타겟팅할때 쓰입니다.

다음은 설정 예시입니다.

```kotlin
val userAttributes = UserAttributes.Builder()
    .attribute("membership_grade", "gold")
    .attribute("purchase_count", 3)
    .attribute("marketing_target", true)
    .build()

MomentSDK.getInstance(context).setUserAttributes(userAttributes)
```

위 key와 value는 예시입니다. 호스트 앱에서 사용하는 타겟팅 기준에 맞게 지정하세요. value는 `string`, `number`, `boolean` 타입을 지원합니다.

사용자의 attribute가 결정되거나 변경되는 시점에 최신 값을 전달합니다.
