## Manage notification copy

Per-campaign notification title/body/landing URL is managed in the **Notification templates** menu.

<Steps>
  <Step title="Choose a template">
    Choose an existing template to edit, or create a new one.
  </Step>
  <Step title="Edit content">
    Edit the title/body/landing URL and set variants (by user attribute, time, etc.).
  </Step>
  <Step title="Preview and save">
    Send a test notification to a test device and save when it looks right.
  </Step>
</Steps>

## Web theme setup (Cashback)

Colors and logos for the Cashback Web UI are managed in **Settings \> Branding**. See [Web Design - Theme](/en/dev-guide/cashback/theme) for details.
