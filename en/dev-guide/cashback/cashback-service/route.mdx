## Overview

If you want to open a specific page rather than the main Cashback page, use the following.

## API

- `launchUI(config, redirectTo, callback)` method reference
  - [fun launchUI(config: Config, redirectTo: String, callback: ResultCallback)](/en/api/android)
- redirectTo: the path Cashback Web will redirect to. Supported pages:
  | Page | redirectTo |
  | :-- | :-- |
  | Specific category on the main page | `/cashback?category=beauty` |
  | Cashback program | `/cashback/detail?business_id=11st` |
  | User earnings history | `/cashback/transactions` |
  | Settings | `/settings` |
  | CS inquiry | `/cs` |

## Code example

```kotlin
val redirectTo = "/pointshop/transactions"

momentSdk.launchUI(
		momentSdkConfig,
		redirectTo,
		object : MomentSDK.ResultCallback {
				override fun onSuccess() {}

				override fun onFailure(exception: MomentException) {}
    }
)
```
