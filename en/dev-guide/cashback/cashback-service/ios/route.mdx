---
title: "Deep-link into a specific page in Cashback Web"
---

If you want to open a **specific page** rather than the main Cashback page, use the following.

- Set redirectTo.
  - `CashbackViewController`
- redirectTo: the path Cashback Web will redirect to. Supported pages:
  | Page | redirectTo |
  | :-- | :-- |
  | Specific category on the main page | `/cashback?category=beauty` |
  | Cashback program | `/cashback/detail?business_id=11st` |
  | User earnings history | `/cashback/transactions` |
  | Settings | `/settings` |
  | CS inquiry | `/cs` |

```swift
val redirectURL = "/cashback/transactions"

let vc = CashbackViewController()
vc.delegate = self
vc.redirectTo = redirectURL
vc.modalPresentationStyle = .fullScreen
present(vc, animated: true)
```
